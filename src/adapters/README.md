# adapters/ — チェーンごとの読み取り部

ここは「そのチェーンの記録を Dispatch Log に翻訳するだけ」の場所です。
**アプリは1つ。増えるのはこのフォルダのファイルだけ**という約束を守ってください。

```
そのチェーンの記録  →  [ adapters/ の関数 ]  →  Dispatch Log  →  画面（共通）
                        ↑ 増えるのはここだけ
```

## 追加の手順

1. このフォルダのファイルを1つコピーして名前を変える（例 `fromFlop.js`）
2. 中の変換だけ書き換える。**出力は Dispatch Log の配列**
3. `index.html` の `<script>` に1行足す
4. 動作確認は開発者コンソールから：

```js
AQ.app.loadEvents(AQ.adapters.fromFlop(myData));
```

これで画面に出れば完了です。`scene.js` も `hud.js` も触る必要はありません。

## 守ること

- **分からないことは書かない。** 送金履歴しか無いなら「払った／確定した」だけを出す。
  「たぶんニュースを買った」のような推測を混ぜると、下の生ログが嘘になります。
- **時刻 `t` はミリ秒。** 並び替えは `questlog.load()` がやります。
- **金額は文字列で。** 浮動小数の丸めで 0.0004 が 0.00039999 になるのを避けるためです。
- 未知の `type` は `tool.call`（移動）として扱われます。落ちはしませんが、
  新しい種別を足したいときは `config.js` の `tier` に1行足してください。

## 入っているもの

| ファイル | 入力 | 用途 |
|---|---|---|
| `fromX402.js` | x402 クライアントのレシート | エージェント側にログがある場合 |
| `fromTransfers.js` | ウォレットの送金履歴 | エージェントが何も出さない場合でも、チェーンだけから再構成 |
| `fromTechnocore.js` | technocore.chat の部屋（生の書き込み） | 誰でも書き込める公開ログを見る |
| `fromKibble.js` | kibble 部屋のパイプ区切り書式（自称 kibble-v1。所有者なし・観測した慣習） | 同上。JOB/CLAIM/DELIVER/ATTEST の依頼ボード風のやり取り |
