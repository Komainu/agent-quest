AGENT QUEST

安全について

Agent Quest は、初心者向けのドット絵の学習アプリです。自分のウォレットをつなぎ、Base に ERC-8004 のエージェントを作って、短いクエストで動かしながら、オンチェーンの AI エージェントのしくみを学びます。無料で、サーバーを持たない1ページだけのアプリです。

ウォレットに頼むこと

どれも、ボタンを押したときだけ頼みます。ページを開いただけでは頼みません。署名や取引の前には、アプリの中で中身（何を頼むか・相手・上限と期限）を見せ、確認のボタンを押してからウォレットを呼びます。

  • 接続（eth_requestAccounts）：アドレスを教えてもらうだけです。
  • ERC-8004 公式の登録先への取引（eth_sendTransaction）：エージェントの登録（register）、名刺の書き換え（setAgentURI）、ほかのエージェントへの評価（giveFeedback）。どれもお金は送らず、ガス代だけです。
  • x402 の支払いの署名（eth_signTypedData_v4）：「ニュースを買う」などを押したときだけ。Base の USDC で、決まったお店に、お店の言い値（ニュースは 0.01 USDC まで）を1回だけ払う署名（EIP-3009 の TransferWithAuthorization）です。お店ごとに受取先と上限をアプリの中に固定してあり、違う条件が来たら署名を頼まずに止めます。期限は最長5分です。

使うコントラクト（Base）

  • IdentityRegistry（ERC-8004）：0x8004A169FB4a3325136EB29fA0ceB6D2e539a432
  • ReputationRegistry（ERC-8004）：0x8004BAa17C55a88189AE136b182e5fdA19dE9b63
  • Base の USDC：0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913

頼まないこと

  • トークンの使用許可（approve・permit・setApprovalForAll）は頼みません。
  • 自前のコントラクトを作ったり、呼んだりしません。
  • シードフレーズ（復元フレーズ）や秘密鍵を入力してもらうことはありません。
  • 開発者へお金を送ることはありません。

もしこのアプリの名前でシードフレーズや秘密鍵を聞かれたら、それは偽物です。入力しないでください。

Agent Quest にもどる

Safety

Agent Quest is a free, beginner-friendly pixel-art learning app. You connect your own wallet, create an ERC-8004 agent on Base, and run it through short quests to learn how onchain AI agents work. It is a single static page with no backend.

What it asks your wallet for

Only when you press a button, never just because the page was opened. Before any signature or transaction, the app first shows you what will be asked (what it is, who it goes to, the limit and how long it is valid), and calls your wallet only after you press the confirm button.

  • Connect (eth_requestAccounts): only to learn your address.
  • Transactions to the official ERC-8004 registries (eth_sendTransaction): register an agent (register), update its card (setAgentURI), and rate another agent (giveFeedback). None of them send money; you only pay gas.
  • x402 payment signature (eth_signTypedData_v4): only when you press a button such as "buy news". It signs a single payment of the shop's asking price (up to 0.01 USDC for news) in USDC on Base to a fixed shop (EIP-3009 TransferWithAuthorization). Each shop's receiving address and limit are fixed in the app; if the shop asks for anything else, the app stops without asking for a signature. The signature is valid for at most 5 minutes.

Contracts it uses (Base)

  • IdentityRegistry (ERC-8004): 0x8004A169FB4a3325136EB29fA0ceB6D2e539a432
  • ReputationRegistry (ERC-8004): 0x8004BAa17C55a88189AE136b182e5fdA19dE9b63
  • USDC on Base: 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913

What it never asks for

  • No token approvals (approve, permit, setApprovalForAll).
  • No contracts of its own: it never deploys or calls custom contracts.
  • It never asks for your secret recovery phrase or private key.
  • It never sends funds to the developer.

If anything using this app's name asks for your recovery phrase or private key, it is fake. Please do not enter it.
