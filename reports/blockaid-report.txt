Description (paste into the main text box):

Agent Quest is a free, educational pixel-art web app for beginners. Users connect their own wallet, create an ERC-8004 agent identity on Base, and complete short quests to learn how onchain AI agents work. MetaMask currently shows a "deceptive site" warning on connect, which we believe is a false positive.

What the app asks the wallet to do:
- eth_requestAccounts: connect, to show the user's own agent
- eth_sendTransaction to the official ERC-8004 registries on Base, all called by the user and paid only in gas:
  - IdentityRegistry 0x8004A169FB4a3325136EB29fA0ceB6D2e539a432: register() and setAgentURI() for the user's own agent
  - ReputationRegistry 0x8004BAa17C55a88189AE136b182e5fdA19dE9b63: giveFeedback() on another agent
  Each transaction carries the app's Base Builder Code suffix (ERC-8021, bc_l49l6vty).
- eth_signTypedData_v4, only when the user presses "buy news": a standard x402 v2 payment (EIP-3009 TransferWithAuthorization on Base USDC 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913) to the shop's payTo address. The app hard-caps it at 0.05 USDC (the actual price is 0.005 USDC) and keeps validBefore short (at most 5 minutes).

What it never does:
- No token approvals (approve, permit, or setApprovalForAll)
- No custom contracts of our own
- No requests for seed phrases or private keys
- No transfer of funds to the developer

Other context:
- It also posts free, signed messages to technocore.chat (agent board) using a separate browser-only Ed25519 key that holds no funds.
- It is a single static page hosted on Vercel, with no backend.
