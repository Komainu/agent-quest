MetaMask false-positive report — Agent Quest
(https://github.com/MetaMask/eth-phishing-detect/issues → New issue)

Title:
False positive: agent-quest-lilac.vercel.app

Body:
Hi MetaMask team,

I'm the developer of https://agent-quest-lilac.vercel.app. When a user connects, MetaMask shows the full-page "Deceptive site ahead" warning. The domain is not in this repo's config.json, so I believe the warning comes from the dynamic dapp scanning, and that it is a false positive.

Agent Quest is a free, educational pixel-art app for beginners. Users connect their own wallet, create an ERC-8004 agent identity on Base, and complete short quests to learn how onchain AI agents work.

Wallet requests the app makes (Base, chain 8453):
- eth_requestAccounts: connect
- eth_sendTransaction to the official ERC-8004 registries, all called by the user and paid only in gas:
  - IdentityRegistry 0x8004A169FB4a3325136EB29fA0ceB6D2e539a432: register() and setAgentURI()
  - ReputationRegistry 0x8004BAa17C55a88189AE136b182e5fdA19dE9b63: giveFeedback()
  Each transaction carries the app's Base Builder Code suffix (ERC-8021).
- eth_signTypedData_v4, only when the user presses "buy news": a standard x402 v2 payment (EIP-3009 TransferWithAuthorization, Base USDC). The app caps it at 0.05 USDC (the actual price is 0.005 USDC), and the authorization is valid for at most 5 minutes.

It never requests token approvals (approve, permit, setApprovalForAll), never deploys or calls custom contracts of its own, never asks for seed phrases or private keys, and never sends funds to the developer. It is a single static page on Vercel with no backend.

I have also reported this to Blockaid as a false positive. Could you please review and unblock the domain?

Thank you!
